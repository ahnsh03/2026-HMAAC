# 하드웨어 구성 부품

출처: PDF p.38–46

## 유아용 전동차

- 후륜 구동 모터 2개 + 조향 모터 1개
- 모두 **12V DC 모터**

## 배터리

- **분실 시 재수령 불가**
- 조교 안내 전까지 **전원 OFF**
- 충전 포트 / 배터리 ON·OFF / 220V AC 출력 ON·OFF

## SMPS

- 220V AC → 12V DC 변환
- AC 입력 전압 설정을 **230V**로
- AC INPUT LED, DC OUTPUT, 전압 조절

## 모터 드라이버

- SMPS 12V DC를 입력으로 받음
- 아두이노 제어 신호 → 모터에 출력 전압 인가
- 전원부(+/-), 모터제어(IN), 모터출력(OUT)

## Arduino Mega 2560

- USB, 전원 핀, 아날로그 입력, 디지털 I/O(PWM), 통신 핀

## 가변저항 (조향 피드백)

- OUT / 5V / GND (스위퍼)
- 아두이노 **A2**에 OUT 연결 (실습 기본)

## 카메라 · 라이다

- 카메라: PC USB 영상 입력
- 2D LiDAR: 각도별 거리 → PC (`/dev/ttyUSB*`)
