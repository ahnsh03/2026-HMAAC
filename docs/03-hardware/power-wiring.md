# 전원부 연결 · 안전

출처: PDF p.89–107

## 절대 금지 (p.90)

- 배터리·SMPS **오배선 → 스파크/화재** 가능
- 강의 자료보다 **앞서 임의 작업 금지**
- 「조교 확인」 표시 단계에서는 **확인 전 진행 금지**
- 확인 전까지 **배터리 OFF**

## 배터리 → SMPS (AC INPUT)

십자 드라이버로 나사 풀고 연결 후 조임 (p.93):

| 선 | 단자 |
|---|---|
| 녹색 | 접지 |
| 파란색 | **N** |
| 갈색 | **L** |

## 모터 선 선별 (p.94–95)

- 조향 모터(갈/파)와 이어진 뒷쪽 선 확인 (가변저항 조립 때 메모한 색)
- 뒷바퀴 모터 선 남김
- **나머지 제거 전 조교 확인**

## SMPS → 모터드라이버 (DC)

| SMPS | 모터드라이버 | 선색 |
|---|---|---|
| **+V** | **9-36V** | 붉은색 |
| **-V** | **PGND** | 검은색 |

**극성 바뀌면 스파크·고장.** 글자 `9-36V` / `PGND`를 눈으로 확인 (p.99).

## 모터드라이버 → 모터

- 모터는 **OUT1 / OUT2만** 연결
- **PGND / 9-36V에 모터 연결 금지** (p.104)
