# 나무프레임 · 카메라 · 라이다

출처: PDF p.118–120

## 나무판 고정

- 카메라 부착 + PC 거치
- 나무프레임 **앞부분**과 도어 **뒷부분** 정렬
- 카메라는 프레임 **중앙**

### 주의 (p.119)

차량을 들 때 **나무프레임을 잡지 말 것**.  
본체(플라스틱)를 잡는다 — 노트북 낙하·손상 위험.

## 라이다 (p.120)

- 2D LiDAR는 **수평 FOV·높이**가 중요
- 트랙에서 장애물 차량 옆에 두고 스캔 영역을 보며 위치·각도 조절
- 확정 후 **글루건 고정**
- 장치 경로: 보통 `/dev/ttyUSB*` — [`vehicle-record-sheet.md`](vehicle-record-sheet.md)에 기록
