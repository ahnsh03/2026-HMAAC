## 준비물 (p.64)

가변저항 홀더, 마운트, 조향축 홀더(3D), 메탈캡, 육각나사, 일체형 볼트, 볼트/너트 세트, 가변저항, 드라이버, 니퍼

## 조립 순서

1. 3D 출력물 **서포트 제거** (니퍼) — p.65
2. 계기판에 가변저항 홀더 **가조립 → 맞는지 확인 → 분리** — p.66
3. 마운트 짧은 쪽에 메탈캡 → 구멍 일치 확인 — p.67–68
4. 육각나사로 가볍게 고정 (너무 꽉 조이지 말 것, 양쪽) — p.69
5. 조향축에 마운트 끼운 뒤 홀더 고정 — p.70
6. 메탈캡 안에 가변저항 → 일체형 볼트 → 볼트/너트, 육각나사 재조임 — p.71–73
7. 조향축 홀더로 유격 제거 (차량 들어 조향축 확인 후 꾹 고정) — p.74
