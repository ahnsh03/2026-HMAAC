# Ⅲ 주행시간 측정

출처: 규정집 ver3.3 p.4 (PDF p.6)

## 측정 구간

1. 차량을 Start에 위치
2. 자율주행차가 **랩타이머를 통과한 시각**부터
3. 트랙 **2바퀴**를 돌아
4. **다시 랩타이머를 통과하는 순간**까지 소요 시간 측정

## 출발 · 종료

| 단계 | 요구 |
|---|---|
| 대기 | 출발 신호 전 SW 전부 실행 · **신호등 탐지 가능** |
| 출발 | 신호등이 **초록불**로 바뀐 순간부터 주행 시작 |
| 출발선 위반 | 출발 신호 **이전**에 정지선(출발선) 초과 → 페널티 (a2) |
| 종료 | 2바퀴 후 **물체 탐지**하여 정지 |
| 최종 기록 | 2바퀴 시간 + **페널티** |
