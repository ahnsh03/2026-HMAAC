# Ⅱ 대회 운영 세부 규정

출처: 규정집 ver3.3 p.2–4 (PDF p.4–5)

## 2.1 기본 규정

### 자율주행 · 하드웨어

- 사전 공지 전동차를 **탑재 소프트웨어만**으로 제어
- 사람·보조기구 도움 **없이** 지정 트랙 자율 주행
- 주최 제공 HW(바퀴, 모터드라이버, 아두이노, SMPS 등) **개조·교체·분해·회로 변경 금지**
- 제공 구성품 외 **전기·기계 부품 사용 금지**
- 검차 시 설치 상태를 **전 경기 유지**

### SMPS

- 전압 **12.0V** 고정 · **승압 금지**
- 검차 후 임의 승압 확인 시 **실격 가능**
- **지정 위치**에 두고 검차 시 전압 측정이 쉽도록 배치
- 측정이 어렵게 설치해 생긴 배선 문제는 **이의 불가**

### 트랙·출발·용어

| 항목 | 내용 |
|---|---|
| 트랙 위 참가자 | **1명** 고정 |
| 출발 | 사전 출발음 후 **마지막 신호**에 맞춤 → 이때부터 재시도 시간 측정 |
| 미출발 | 출발 신호 후 **10초 이내** 미출발 → 재시도 1회 |
| 주행시간 | 차량이 **랩타이머 기준선** 통과 시점부터 자동 측정 |
| 1차선 | 안쪽 차선 · IN=안쪽 흰색 **실선**, OUT=바깥쪽 흰색 **점선** |
| 2차선 | 바깥쪽 차선 · IN=안쪽 흰색 **점선**, OUT=바깥쪽 흰색 **실선** |
| 경기 형태 | 시간 측정 → 시간(+페널티)을 점수로 환산해 순위 |
| 기회 | **4분** · 팀당 **한 번의 기회** · 시작 후 1분 이내 시간 중단 없이 **재출발 1회** 가능 |
| 대기 | 출발 신호 전 SW **전부 실행**, **신호등 탐지 가능** 상태 |

### 출발 준비 · 포기

- Start 선에 센서 포함 **차량 앞부분** 위치
- 위치 후 **2분 이내** 출발 준비 완료 · 초과 시 심판이 임의 출발 신호
- **주행 포기 없음** · 4분 경과 또는 진행 불가 = **완주 실패**
- 진행 불가 시 **구역 미완주 + 진행불가 벌점** 모두 부여

### 정의

| 용어 | 정의 |
|---|---|
| 차선침범 | 한쪽 바퀴가 흰색 **점선**을 밟음. 동일 점선에 바퀴 1개 이상 접촉 = 침범 1회 |
| 차선이탈 | 한쪽 바퀴가 흰색 **실선 또는 점선**을 **넘어감** |

> **구두 보강 (2차로, 08-13):** 왼쪽 점선은 **밟기만 해도** 페널티. 오른쪽 실선은 **밟아도** 페널티 없음. **어느 쪽이든 선을 넘어가면** 이탈 페널티. 상세 [verbal-briefing.md](verbal-briefing.md).
| 재시도 | 출발 안 됨 · 파워 ON/OFF·프로그램 재설정 가능 · **최대 1회** |
| 재위치 | 차선 이탈 후 원 경로 복귀 불가 · 심판 지정 위치로 · **최대 3회** |
| 장애물 설치 | 팀원 1명이 지정 위치에 직접 설치 |
| 정지 위치 | 앞바퀴 = 신호등 정지선 **앞쪽**, 뒷바퀴 = 같은 선 **뒤쪽**. 실패 시 장애물까지 거리 ≤1m → **a4**, >1m → **a3** |

## 2.2 시간측정 경기

- 출발: Start 선 · 센서 포함 **최앞부가 출발선 초과 금지**
- **2차선**을 따라 **반시계 방향 2바퀴**
- 참가자는 심판과 트랙 **바깥쪽**에서 차량을 따르고, **심판 뒤에** 위치
- 최종 점수 = 랩타이머 2바퀴 통과 시간 + **페널티**
- 재시도/재위치 소요 시간 **모두 포함** · 4분 초과 = 완주 실패
- 순위: 페널티 합산 최종 기록이 **짧은 순**
- IN-라인(점선): 침범·이탈 모니터링 / OUT-라인(실선): 따라가는 심판이 이탈 판단
- 심판이 차선 **바깥쪽**에서 감독 → 센서 오측 이의 **불가** (프로그래밍 시 감안)
- 이탈 판정 시 심판이 이탈 지점 **이전**으로 재위치 지정 · 참가자는 트랙 안 들어와 차량 **후방을 들고 후진**해 재위치

## 2.3 자율주행 차량 기술 규정

- 교육에서 제시한 차량·센서·배터리·모터 규격만 사용
- 센서 부착 한계: 전후 **110cm**, 좌우 **60cm**, 높이 **75cm** 초과 금지
- 제한 범위 내 센서 지그 제작·설치 **가능**
- 센서 부착·디자인 외 **기타 개조 불허**

## 2.4 평가

최종 순위 = 시간 측정 경기 순위(기록 짧은 순).

## 2.5 검차

- 검차 점검표로 **자체 점검** 후 심사위원 판정
- 경기 전 검차 · 위반(부품·센서 위치 등) → **실격**
- **30분 이내** 수정 가능하면 **재검차 1회**
- 상위 입상 팀 **정밀 검차**

## 2.6 이의신청

- 전 경기 종료 후, **정해진 이의신청 시간**에만 · **팀장**이 위원회에 제기
- 경기 중 판정만 · **정확한 시점** 명시
- **본인 팀** 관련만 (타 팀 이의 불가)
