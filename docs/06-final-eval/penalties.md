# Ⅴ 페널티 규정

출처: 규정집 ver3.3 p.8 (PDF p.10)

## 시간측정 경기 페널티표

### 출발 · 도착

| 코드 | 내용 | 페널티 |
|---|---|---|
| **a1** 재시도 | 출발 신호 후 10초 이내 미출발 (재시도 후 50초 이내도 미출발이면 종료) | 재시도 + **30초** |
| **a2** 출발 실패 | 출발 신호 **이전**에 정지선(출발선) 초과 | **50초** |
| **a3** 정지 실패 | 물체 탐지 후 미정지 또는 장애물 **충돌** | **50초** |
| **a4** 정지선 이탈 | 정지는 했으나 위치 부정확 (장애물까지 ≤1m) | **10초** |
| **a5** 종료 | 4분 이내 2회(2바퀴) 주행 미완료 · 물체 탐지 정지 미구현으로 간주 | **완주 실패** |

### 트랙 주행 · 이탈

| 코드 | 내용 | 페널티 |
|---|---|---|
| **b1** 재위치 | 차선 **이탈** 판정 (바퀴 1개가 선을 **넘어감**. 그 외는 침범) | 재위치 + **15초** |
| **b2** 전진불가 재위치 | 트랙 내 **5초 이상** 정지(전진 불가) | 재위치 + **20초** |
| **b3** 침범 | 흰색 **점선** 침범 (동일 점선에 바퀴 1개 이상 접촉 = 1회) | 회당 **10초** |
| **b4** 랩타이머 충돌 | 랩타이머와 충돌 | **30초** |

### 진행 불가

| 코드 | 내용 | 페널티 |
|---|---|---|
| **c1** 진행불가 | 재위치 직후에도 주행 불가 (대기 최대 30초) | **완주 실패** |
| **c2** 횟수 초과 | **4회 이상** 재위치 | **완주 실패** |

## 개발 시 우선 막을 페널티

1. **a2** — 초록불 전 출발선 넘지 않기 (신호등 대기 로직)
2. **b3 / b1** — **왼쪽 점선은 밟기만 해도 b3**. 오른쪽 실선은 밟아도 OK, **어디든 넘어가면 b1**
3. **a3 / a4** — 종료 시 **차량 감지 정지** + 규정집 정지 위치
4. **b4** — 랩타이머 경로 여유
5. **b2** — 5초 이상 스톨 방지
6. **a5 / c1 / c2** — 4분·재위치 횟수 한도 내 완주
