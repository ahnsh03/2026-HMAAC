# Ⅰ 대회 규정

출처: 규정집 ver3.3 p.1 (문서 페이지 1, PDF p.3)

## 제1조 목적

H-모빌리티 클래스 자율주행 심화과정 주행 평가의 **공정한 운영**.

## 제2조 운영 방식

- 경기 운영은 **주행 평가 당일**에 진행
- 규정집에 없는 문제·해석 논란 → **주최 측 최종 결정**

## 제3조 준비

- 참가 인원 대상 필요 교육 진행
- **연습 주행은 평가 3시간 전까지만** 제공
- 지정 차량·센서 규격에 맞춰 각 팀이 준비

## 제4조 세부 규정

- 채점은 **페널티 규정**을 따름 → [penalties.md](penalties.md)
- 페널티 판정은 **경기심판** 권한
- 이의는 **경기 종료 후**, **당일 주어진 시간**에만 가능 → [operations.md](operations.md) 2.6
