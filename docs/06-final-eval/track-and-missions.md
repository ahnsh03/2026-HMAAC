# Ⅳ 트랙 구성 및 미션

출처: 규정집 ver3.3 p.5–7 (PDF p.7–9)  
트랙 도면 이미지는 **규정집 PDF p.6–7 (문서 p.6–7)** 직접 확인.

## 4.1 주요 치수

| 항목 | 치수 |
|---|---|
| 도로 폭 | **850 mm** |
| 차선(실선·점선) 폭 | **50 mm** |
| 시작선 폭 | **100 mm** |
| 횡단보도 | **1000 × 100 mm** |
| 주차 공간 | **950 × 1500 mm** |

직선·곡선 주로로 구성.

## 4.2 출발선

- 출발 전: SW 실행 + 신호등 탐지 대기
- 출발 신호 **이전**에 정지선 초과 → 페널티

## 4.3 차선

- 흰색 실선·점선으로 일반 도로 차선 모방
- **두 차선** · 지정 차선(시간측정 경기는 **2차선**)을 따라 **반시계** 주행

## 4.4 랩타이머 충돌

| 시점 | 조치 |
|---|---|
| 출발 시 충돌 | 페널티 + 재위치 (**T1**) |
| 1바퀴 통과 직전 충돌 | 페널티 + 재위치 (**T4**) |
| 종료 직전 충돌 | 페널티 + 재위치 (**T4**) |

페널티 시간 코드는 [penalties.md](penalties.md)의 `b4`(랩타이머 충돌 30초)와 함께 적용 맥락을 본다.
