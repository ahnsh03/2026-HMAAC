# 개발 · 검차 체크리스트

출처: 규정집 ver3.3 전반 · 상세는 형제 문서 링크

개발하면서 기능·하드웨어가 규정에 맞는지 이 목록으로 확인한다.

## 하드웨어 · 검차

- [ ] 제공 차량·모터드라이버·아두이노·SMPS·바퀴만 사용 (추가 전장·기계 부품 없음)
- [ ] HW 개조·회로 변경 없음 · 검차 상태 유지
- [ ] **SMPS = 12.0V** · 승압 안 함 · 측정하기 쉬운 위치에 배치
- [ ] 센서 설치: 전후 ≤**110cm** / 좌우 ≤**60cm** / 높이 ≤**75cm**
- [ ] 센서 지그는 위 범위 안 · 디자인 외 개조 없음
- [ ] 자체 검차표 점검 → 재검차 여유(30분·1회) 인지

## 미션 · SW 동작

- [ ] 출발 전: 주행 SW **전부** 기동 · **신호등 탐지** 가능 상태로 대기
- [ ] **초록불** 감지 후에만 출발 (조기 출발 = a2)
- [ ] 주행: **2차선** · **반시계** · **2바퀴**
- [ ] 랩타이머 통과로 시간 측정되는 경로 유지 · 충돌 회피 (b4)
- [ ] 차선: 점선 접촉(침범)·실선/점선 이탈 최소화
- [ ] 심판이 **차선 바깥**에 있어도 센서/인지가 깨지지 않도록 설계 (이의 불가)
- [ ] 2바퀴 후 **물체 탐지 → 정지**
- [ ] 정지 위치: 앞바퀴는 정지선 **앞**, 뒷바퀴는 선 **뒤** (아니면 a4/a3)
- [ ] 4분 내 완주 가능 속도·재시도/재위치 전략 (재시도 1 · 재위치 ≤3)
