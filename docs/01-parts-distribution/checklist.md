# Ⅰ 부품 배부 체크리스트

출처: PDF p.9–18

팀원 역할을 나눠 수령한 뒤, 아래를 체크한다.

## 수령

- [ ] ① 차량 수령 (팀원 2명)
- [ ] ② 노트북 + 배터리 + 마우스/패드 수령 (팀원 2명)
- [ ] ③ 부품박스 + 나무프레임 수령
- [ ] ③ 부품박스 물품 리스트에 **조 이름** 기입
- [ ] ③ 부품별 **수량 이상 유무** 확인·체크
- [ ] ④ 강의 교재 (인원당 1권)
- [ ] ④ 로고 스티커 (원형×1, 사각형×2)

## 스티커 · 라벨

- [ ] ⑤ 차량·나무프레임의 **기존 스티커 제거**
- [ ] ⑤ 전면 그릴에 로고(스티커 아님)가 남아 있으면 **조교 호출**
- [ ] ⑥ 차량에 **원형** H-모빌리티 스티커 부착
- [ ] ⑥ 나무프레임 양 측면에 **사각형** 스티커 부착
- [ ] ⑦ 메모지에 `H-모빌리티 (조이름)` 작성 후  
      차량 / 배터리 / 부품박스에 부착하고 **조교 확인**

## 주의

- 노트북 비밀번호(교육 노트북): `1234` (Wi-Fi 장에서 재확인)
- 배터리·부품 분실 시 재수령 불가에 가까운 규칙이 있으므로 라벨을 꼭 붙인다.
