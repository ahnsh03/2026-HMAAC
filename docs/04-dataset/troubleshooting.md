# 데이터셋 수집 — 트러블슈팅

출처: PDF p.140–141

## 동작 이상

| 증상 | 점검 |
|---|---|
| 앞바퀴가 한쪽으로 꺾인 채 안 움직임 | 조향 모터 핀 (Arduino 2/3) |
| 전진/후진이 반대 | 후륜 모터 핀 (4–7) 교차 확인 |
| 시리얼/ROS 포트 에러 | Arduino IDE **시리얼 모니터 종료** |
| 카메라 안 열림 | `CAMERA_NUM`이 `ls /dev/video*`의 **짝수**인지 |

## 장치 이름 재확인

```bash
ls /dev/ttyACM*
ls /dev/video*
ls /dev/ttyUSB*
```

## 핫플러그 주의 (p.141)

프로그램 실행 중 USB(카메라/아두이노/라이다)를 뽑았다가 다시 꽂으면  
`ttyUSB0 → ttyUSB1`처럼 **장치명이 바뀌어** 노드가 실패할 수 있다.

- 긴급 상황 제외: **관련 프로그램 종료 후** 분리
- 변경되면 기록 시트의 장치명·코드 파라미터를 갱신
